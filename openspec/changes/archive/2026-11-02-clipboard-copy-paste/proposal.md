# Proposal

## Why

現在要重複畫出相同的結構，只能一個一個重建：流程圖的一串節點加箭頭、類別圖裡相似的 Class、循序圖裡重複的訊息往返。三種圖都已經有選取、刪除和復原，只差複製、剪下、貼上這一塊，補上之後編輯效率會明顯提升。

## What Changes

- 三種圖都支援 Ctrl+C（複製）、Ctrl+X（剪下）、Ctrl+V（貼上）。macOS 的 Cmd 一樣可以用。
- 剪貼簿放在程式內部記憶體，不用系統剪貼簿。可以貼到同一個專案的其他圖分頁，但只能貼到同類型的圖。重新整理後剪貼簿就清空。
- **流程圖**：複製選取的節點和子圖框；子圖框會連同成員一起複製；兩端都在選取內的箭頭也一起複製。貼上時產生新的 id，位置往右下偏移。
- **類別圖**：複製選取的 Class、註解和套件框；兩端都在選取內的關係一起複製。貼上時，目標圖上還沒有這個 Class 就直接放原元素；已經在圖上才在模型建立副本（含成員，名稱加後綴）。所以剪下再貼上等於搬移，不會多出副本。
- **循序圖**：複製選取的訊息、註解和片段，貼在目前選取項目之後，沒選取就貼在最後。跨圖貼上時，依名稱對應生命線，找不到就新增一條。
- 共通規則：
  - 剪下 = 複製 + 刪除，一次就能復原。
  - 貼上後改為選取新貼上的內容，一次就能復原。
  - 正在輸入框裡編輯文字時不攔截快捷鍵，文字照常複製貼上。

不在本期範圍：
- 系統剪貼簿、跨瀏覽器分頁或跨專案貼上
- 跨圖類型貼上（例如把流程圖節點貼到類別圖）
- 複製循序圖的生命線本身
- 工具列或右鍵選單上的複製貼上按鈕
- 貼在滑鼠游標位置

## Capabilities

### New Capabilities
（無）

### Modified Capabilities
- `diagram-editing`：新增「複製、剪下與貼上」需求，涵蓋三種圖的複製範圍、貼上規則與復原行為。

## Impact

- `src/model/ops.ts`：新增擷取剪貼簿內容與貼上的純函式（三種圖各一組），以及循序圖「整個移除片段」的操作（現有 `deleteItem` 對片段是解除框）。
- `src/model/ops.test.ts`：補上複製、貼上、剪下的測試。
- `src/store/editor.ts`：新增剪貼簿狀態（不進復原紀錄、不存檔）。
- `src/canvas/flowchart/FlowchartView.vue`、`src/canvas/class/ClassDiagramView.vue`、`src/canvas/sequence/SequenceDiagramView.vue`：在各自的 `onKeyDown` 加上 Ctrl+C／X／V 的處理。
- 專案檔格式不變，也不新增相依套件。
