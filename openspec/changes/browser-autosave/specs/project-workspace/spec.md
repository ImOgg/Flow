# Spec Delta

## ADDED Requirements

### Requirement: 瀏覽器自動暫存
系統 SHALL 在專案內容變更後，自動把整份專案暫存在使用者的瀏覽器本機，暫存內容永遠等於目前畫面。開啟頁面時有可用的暫存，系統 SHALL 直接還原，不詢問。還原的專案 SHALL 標記為未儲存，而且不關聯任何檔案。暫存只是保險，不取代存檔。暫存的寫入或讀取失敗時，系統 SHALL 忽略，不影響編輯，也不顯示錯誤。

#### Scenario: 重新整理後還原
- **WHEN** 使用者編輯專案後約 1 秒，重新整理頁面
- **THEN** 畫面顯示重新整理前的模型與圖，專案標記為未儲存，檔名顯示為未命名

#### Scenario: 開檔後暫存跟著換
- **WHEN** 使用者開啟一個專案檔，接著重新整理頁面
- **THEN** 畫面顯示該檔案的內容

#### Scenario: 還原的內容放棄前要確認
- **WHEN** 頁面剛還原暫存，使用者選擇「新專案」或開啟其他檔案
- **THEN** 系統先詢問是否放棄未儲存的變更

#### Scenario: 還原後存檔
- **WHEN** 頁面剛還原暫存，使用者選擇「儲存」
- **THEN** 系統要求選擇檔案位置，寫入後清除未儲存標記

#### Scenario: 沒有暫存
- **WHEN** 使用者第一次開啟頁面，瀏覽器裡沒有暫存
- **THEN** 系統顯示空白專案

#### Scenario: 暫存內容損毀
- **WHEN** 開啟頁面時，暫存內容不是有效的專案資料
- **THEN** 系統忽略暫存，顯示空白專案，不顯示錯誤訊息

#### Scenario: 無法寫入暫存
- **WHEN** 瀏覽器拒絕寫入暫存，例如容量不足或無痕模式的限制
- **THEN** 使用者可以照常編輯與存檔，不顯示錯誤訊息
