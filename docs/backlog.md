- **連線可拖動調整**（2026-10-08）
  - 目前連線自動走直角折線，無法調整（design D6 的 MVP 取捨）
  - 建議做法 A：拖動中間那一段，調整轉折位置（水平走向的線上下拖、垂直的左右拖），每條邊只多存一個偏移量

## 操作引導（2026-10-13 許願）

- **空白畫布引導**：圖還沒有內容時，在畫布中央顯示 3～4 行「怎麼開始」，放了第一個東西就自動消失
  - 起因：第一次開流程圖不知道要「選工具 → 點畫布」，以為可以從模型樹拖
  - 不建議做常駐的側邊說明：會佔畫布寬度，內容也跟提示列重複
  - 建議做法：`Canvas.vue` 加 `empty` slot，疊在 svg 上（同 `.zoom` 的作法）；三個 View 用既有的 `isEmpty` 判斷顯示
  - 注意：引導區塊要 `pointer-events: none`，否則會擋住「點畫布中央放第一個節點」；放在 HTML 層，匯出時本來就不會帶到
  - 文案草稿：
    - 流程圖：選上方形狀後點畫布放節點／選取節點按 Tab 接下一步／用「箭頭」從節點拖到節點
    - 類別圖：選 Class 後點畫布，或從左邊模型樹拖進來／雙擊區塊新增成員／用關係工具從來源拖到目標
    - 循序圖：在上方輸入框輸入 `A -> B: login()` 後按 Enter
  - 之後若需要完整說明（快捷鍵總表），再加「?」按鈕
- 流程圖提示列的預設文字沒寫「選形狀 → 點畫布放置」，可以一起補上

## 瀏覽器自動暫存（2026-10-22 許願）

- 自動暫存已完成（2026-10-23，`browser-autosave`），以下為延後項目
- **記住上次開的檔案**：目前還原後沒有檔名，第一次存檔會要求選位置。`FileSystemFileHandle` 存不進 localStorage，要用 IndexedDB，重新開啟時瀏覽器會再要一次權限
